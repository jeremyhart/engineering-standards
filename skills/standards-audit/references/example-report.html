06 · Why now

The case for spending three days on this

This system holds the only copy of customer order data, which is why it is graded at level 3. Two of the gaps could expose that data — a secret sitting in git history and database tables that allow access by default rather than denying it. Neither is a rewrite; both are configuration. The whole action list is roughly three days of engineering time. Deferring compounds the cost, because every feature built from here inherits the same gaps and has to be revisited later. This is not new work for its own sake — it is the maintenance that keeps features shipping at the pace you see today, without a security incident interrupting the roadmap.

Both data-exposure items are config-level fixes, not projects: push protection plus a CI scan step, and a deny-all RLS migration followed by explicit grants. The type-safety and lint gates are one-liners in ci.yml that stop the drift already visible on main — 4 type errors and 14 unformatted files. Infrastructure as code is the only item with real scope, and it can start with the Cloudflare config alone. Nothing on this list blocks feature work or requires a freeze; each item lands as an independent PR and can be picked up between features.
