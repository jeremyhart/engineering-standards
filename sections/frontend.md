# Frontend

*Only relevant if the project has a user-facing UI.*

## Accessibility baseline

The interface is usable by people who don't use it the way you do.

| Level | Definition | Effort |
|---|---|---|
| 1 · Personal | — | |
| 2 · Shared | Semantic markup and labelled controls; the app is navigable by keyboard alone | M |
| 3 · Critical | Automated accessibility checks run in CI with zero critical violations; contrast and focus states meet the standard | M |
| 4 · Contracted | Manual keyboard and screen-reader passes on the main flows, repeated when those flows change; known gaps recorded | L |
